# PH Videos Auto-Play

### Description
The extension automatically plays the next video in the module when the current one finishes.

It includes a toggle switch, allowing you to easily enable or disable the videos Autoplay option.

---

### Installation Guide (Developer Mode)

Because this is a custom-built extension, you can load it directly into your browser using Chrome's Developer Mode. Follow these steps to install:

1. **Download the Project:** Download this repository as a `.zip` file and extract the folder to a location on your computer.
2. **Open Chrome Extensions:** Open Chrome and go to `chrome://extensions/`.
3. **Enable Developer Mode:** In the top-right corner of the Extensions page, find the **Developer mode** toggle switch and turn it **ON**.
4. **Load the Extension:** Click the **Load unpacked** button that appears in the top-left corner of the page.
5. **Select the Folder:** Browse your computer and select the extracted folder (e.g. `PH_Videos__AutoPlay-main`) that contains the `manifest.json` file.
6. **Pin for Easy Access:** Click the **Extensions icon** in your Chrome toolbar, find **PH Videos Auto-Play**, and click the pin icon to keep the toggle switch easily accessible.
